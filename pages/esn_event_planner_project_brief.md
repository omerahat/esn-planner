# Project Brief: ESN Community Event Planner

## 1. Project Overview
A web-based event planning and management platform designed specifically for **Erasmus Student Network (ESN)** chapters. The tool enables community managers to visualize monthly schedules, track special holidays, and assign team members to specific events using an intuitive, drag-and-drop-inspired interface.

## 2. Objectives
- **Streamline Planning:** Replace fragmented tools with a centralized calendar for monthly event coordination.
- **Enhance Collaboration:** Make team assignments transparent and easy to manage.
- **Cultural Awareness:** Integrated "Special Days" tracking (religious, national, and international holidays) to assist in inclusive scheduling.
- **Data Portability:** Enable exporting of plans to standard formats for sharing and reporting.

## 3. Core Features
- **Interactive Monthly Calendar:** High-level view of all planned events with full event titles and assigned leads visible.
- **"Special Days" Sidebar:** A dedicated panel listing relevant holidays and cultural dates for the selected month.
- **Member Management:** A sidebar listing community members with roles, designed for easy assignment to events.
- **Event Creation Panel:** A slide-over form to input event names, locations, dates, and select committee members.
- **Export Functionality:** Support for exporting data to **Google Sheets**, **PNG (Image)**, and **Calendar (.ics)** formats.

## 4. Visual Identity (Unity & Exchange Design System)
- **Primary Color:** ESN Cyan (#00aeef) used for primary actions, branding, and active states.
- **Typography:** *Plus Jakarta Sans* for a modern, clean, and professional feel.
- **Layout:** A structured, multi-column dashboard layout (Side Navigation + Main Content + Action Sidebar).
- **Style:** Clean, airy, and professional, adhering to the ESN "Unity & Exchange" brand guidelines.

## 5. User Flows
1. **Viewing the Schedule:** Users log in to see the current month's calendar and upcoming special days.
2. **Creating an Event:** Users click "New Event" or a calendar day to open the creation panel, fill in details, and assign members.
3. **Assigning Members:** Users can view the member list and see who is available or currently assigned to tasks.
4. **Exporting Data:** Users use the "Export" dropdown to download the schedule in their preferred format.
